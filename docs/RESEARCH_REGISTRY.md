# Research registry

Public evidence reviewed 2026-11-26. Decisions are for the design. Validate exact versions, licenses, terms, weight artifacts and costs before provisioning. No dataset or model was downloaded or benchmarked.

| Resource | Availability and commercial terms | Finding, limitation and decision | Integration and incremental cost |
|---|---|---|---|
| WEBSHORTS | Public preprint. Dataset download, asset rights and commercial training license unverified. [Author preprint](https://arxiv.org/abs/2605.18653) | Incorporate as-of trend snapshots and delayed-label evaluation as design ideas. Reported ~14k clips and seven-day views are a limited horizon and domain. Hold dataset, checkpoints and code pending verification. | Local snapshots feasible after source approval. External retrieval and inference costs unknown. |
| What Makes Online Content Viral? | Public author PDF. Publication is copyrighted. Read findings and cite. No reuse permission inferred. [Paper](https://katherinemilkman.squarespace.com/s/what-makes-online-content-viral.pdf) | Test arousal, surprise and practical utility as hypotheses. News-article sharing and experimental results do not establish causal short-video cash lift. Reject fixed paper-derived weights. | Hand rubric has no license fee or external inference. |
| MicroLens | Public landing page and raw data access process. Academic-only dataset terms. [Maintainer documentation](https://github.com/microlens2023/microlens-dataset) | Reject commercial dataset ingestion. Inform multimodal ablations from paper. Recommendation interactions are not publishing outcomes. | No import. Raw video and training would add storage/compute. |
| KuaiRand | Public releases, repo advertises CC BY-SA 4.0. Verify artifact and supplement scopes, attribution, privacy and downstream obligations. [Repository](https://github.com/chongminggao/KuaiRand) | Adopt randomized exposure and logged propensity concepts. Kuaishou intervention population does not identify AAME payout effects. Defer data import. | Smaller Pure release available. Import entails bandwidth, storage and review only if enabled. |
| KuaiRec | Public releases, repo advertises CC BY-SA 4.0. Verify each artifact and supplement separately. [Repository](https://github.com/chongminggao/KuaiRec) | Adopt coverage and missingness checks. Dense interaction subset represents selected users/items. Defer import and reject using it to calibrate virality. | Offline benchmark feasible only with confirmed scope and measured storage. |
| Moment-DETR | Public code listed MIT. QVHighlights annotations CC BY-NC-SA 4.0. Media, pretrained weights and dependencies need separate clearance. [Repository](https://github.com/jayleicn/moment_detr) | Query-conditioned moment localization can benchmark candidate recall. Salience labels are not virality. Hold weights and reject noncommercial annotations in commercial workflows. | Heavier extraction and possible GPU. No cost baseline until measured. |
| Lighthouse | Public LINE implementation. Code Apache-2.0. Check checkpoint, backbone, training data and asset terms individually. [Repository](https://github.com/line/lighthouse) | Defer moment-retrieval experiments until baseline value and permissions justify. Demos do not measure short-video cash. | Pin eligible dependencies and measure accelerator time before activation. |
| YouTube Data API | Official docs describe OAuth uploads and quota buckets. Terms and per-project status govern usage. [Upload](https://developers.google.com/youtube/data/reference/rest/v3/videos/insert) · [Quota and audits](https://developers.google.com/youtube/data/guides/quota_and_compliance_audits) · [Policies](https://developers.google.com/youtube/terms/developer-policies) | Conditional metadata/publishing adapter. The November 2, 2026 policy revision removed private-only uploads for unverified projects. Set privacy explicitly and verify effective quota, visibility, permitted storage and derived uses. [Revision history](https://developers.google.com/youtube/data/revision_history) No acquisition rights follow from metadata access. | Start inside permitted quotas. No paid quota workaround. Actual project untested. |
| YouTube Analytics API | Official OAuth reports and per-report metric support. Access requires eligible channel/account grant. [Metrics](https://developers.google.com/youtube/analytics/metrics) · [Queries](https://developers.google.com/youtube/analytics/reference/reports/query) | Conditional retention and estimated revenue adapter. Reporting lag, missing combinations and visibility restrict comparison. Estimates enter estimate ledger. | Batch only permitted queries. No paid dependency assumed. Actual access untested. |
| Google Trends | Public UI and application-gated official API alpha. Access, quota, reuse and pricing for AAME unverified. [Official API](https://developers.google.com/search/apis/trends) | Optional relative search-interest feature. Geography, scaling and search interest differ from short-video demand. Defer automation pending access. | Use permitted operator snapshots or neutral fallback. API cost unknown. |
| Whisper | Public local code and weights under MIT. Retain notices. [OpenAI repository](https://github.com/openai/whisper) | Adopt local transcription. Test noise, multilingual audio, entity errors, hallucinations and timestamp alignment. | No license fee. Benchmark pinned small model on available hardware and bound runtime. |
| FFmpeg | Public project. Generally LGPL; build flags can change obligations, and some configurations are nonredistributable. Verify codecs, patents and redistribution before distributing. [FFmpeg legal](https://ffmpeg.org/legal.html) | Adopt local probe, transcode and caption rendering. Media input remains untrusted. | No hosted tool fee. Pin approved build and measure CPU/disk. |
